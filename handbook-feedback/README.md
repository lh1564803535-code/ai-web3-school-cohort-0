# Handbook Feedback

把读 Handbook 时发现的问题、错别字、概念不清楚、资料过期、结构建议沉淀到这里。  
每条 feedback 一个 markdown 文件：`YYYY-MM-DD-<slug>.md`。

## 模板

```markdown
# <一句话标题>

- Handbook 页面：https://aiweb3.school/zh/handbook/...
- 类型：错别字 / 概念不清 / 资料过期 / 结构建议 / 内容缺失
- 日期：YYYY-MM-DD

## 问题

引用原文（30 字内）+ 描述具体问题。

## 建议改法

具体怎么改，最好给出替代措辞或新增小节标题。

## 来源 / 旁证

参考资料链接、自己跑过的实验、或对比其他文档。
```
